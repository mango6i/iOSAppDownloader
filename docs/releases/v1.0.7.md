# iOSAppDownloader v1.0.7

## 中文

本版本修复 v1.0.6 无法登录、登录组件异常退出以及双重认证流程无法继续的问题。

- 移除不稳定的 `pywinpty/ConPTY` 登录路径，解决 `0xC0000142` 和 Rust `unwrap` 异常。
- 恢复 `ipatool-rs` 非交互式登录流程；首次登录请求仍负责触发 Apple 的双重认证，验证码提交会复用相同网络线路。
- 提交验证码后自动确认真实账号会话，减少正确验证码被误报失败的情况。
- 修复验证码提交后 Apple 仍要求双重认证时又自动发起无验证码登录补救的问题，避免界面表现为“一直提交”。
- 关闭或退出软件时会主动撤销并删除本地 Apple 登录会话，下次打开需要重新登录和重新完成双重认证。
- 修复已登录账号首次查询免费应用时的 `empty songList` 错误：官方查询同时使用 App ID 和 Bundle ID，并在账号尚未获取该应用时自动获取一次免费许可后重试；不会自动购买付费应用。
- 如果 Apple 在获取免费许可后仍返回空官方列表，自动回退到“免登录查询”填充历史版本表，不再弹窗阻断操作。
- 将 `ipatool.exe` 打包到隔离目录，避免和 Python/Qt DLL 冲突。
- 清理构建工作流：失败日志改为 Actions 临时附件，不再自动提交到源码仓库。

## English

This release fixes the v1.0.6 sign-in failure, login-component crashes, and interrupted two-factor authentication flow.

- Removes the unstable `pywinpty/ConPTY` sign-in path and its `0xC0000142`/Rust `unwrap` failures.
- Restores non-interactive `ipatool-rs` authentication; the first request initiates Apple verification and code submission reuses the same network route.
- Confirms the real account session after code submission to avoid falsely rejecting a valid code.
- Stops the automatic no-code recovery when Apple still explicitly requires two-factor authentication after code submission, preventing the UI from looking like it is repeatedly submitting the same code.
- Revokes and deletes the local Apple sign-in session when the app exits, so the next launch requires signing in and completing two-factor authentication again.
- Fixes `empty songList` when a signed-in account checks a free app for the first time by using both App ID and bundle ID, obtaining the free license once, and retrying. Paid apps are never purchased automatically.
- Falls back to Login-free lookup when Apple still returns an empty official list after the free-license retry, keeping the history table usable instead of blocking with an error dialog.
- Packages `ipatool.exe` in an isolated directory to avoid Python/Qt DLL conflicts.
- Stores failed CI logs as temporary Actions artifacts instead of committing them into the source repository.
