# iOSAppDownloader v1.0.8

发布日期：2026-11-22。Windows 成品：`iOSAppDownloader_v1.0.8.exe`。

## 更新内容

- 修复 Windows 构建机换行转换导致的组件校验失败：统一构建输入换行，保留固定 SHA-256 校验。
- 修复官方历史和下载均报 `available storefronts request failed`：为生产组件加入与界面共享的 134 个已知商店区域映射，避免已知账号区域依赖在线区域列表；未知区域保留上游动态识别，不猜测为国区或美区。
- 登录 / 确认账号时输出安全的 `storeFront` / `countryCode` 元数据，并在登录成功提示前同步搜索区域；切换区域清理旧结果。同一账号普通状态刷新不覆盖手动区域选择，重新登录或更换账号则重新同步。

- 修复成品搜索 `[Errno 2] No such file or directory`：完整打包构建运行时需要的 HTTPS 校验依赖文件，保留原有校验策略；成品检查新增 HTTPS 初始化验证。

- 修复准备认证时下载 Apple 根证书返回 HTTP 403：内置指纹固定的 Apple 官方根证书，仅用于认证客户端的内存信任池，不修改 Windows 证书库、不需要管理员权限、不关闭 HTTPS 校验。
- 认证进度不再显示 ipatool 名称和版本，准备提示按界面语言显示。
- 中国区、结果数量、历史来源、界面语言等下拉框统一使用绘制的“﹀”箭头，修复灰色方块。
- 源码构建过程、上游校验值与兼容构建校验值见 `ipatool/majd/README.md`；不是未修改的上游 EXE，也不是新的独立认证协议。

- 基于官方 ipatool 2.8.1 源码的兼容构建，使用新版认证、本地 Anisette 配置、商店协议及内部并行下载能力；不使用浏览器或第三方签名服务。
- 同步上游商店协议、动态区域发现、已获取下架应用恢复及组件内部并行下载改进，保留原有历史版本、免登录查询及下载队列界面。
- 验证码续接保留当前 Cookie 和新版认证状态，固定使用发起挑战的线路，不跨线路重复提交验证码。
- 登录准备阶段实时显示官方组件状态；首次新版组件初始化预留最多 5 分钟，关闭设置仍可取消。
- 保留 Apple 返回的账号处理提示和链接，不再把组件准备日志混入主要错误，不将所有失败误报为验证码错误。
- 修复首页“请先登录”提示底部开源链接裁切；按最终字体计算正文高度，为末行留出空间。
- 设置底部仅显示“软件版本：v1.0.8”，移除认证组件版本字样。
- 正式成品为 `iOSAppDownloader_v1.0.8.exe`；组件来源、压缩包和 EXE 均固定 SHA-256，打包后检查真实内置版本及界面布局。

## 验证与使用提醒

- 75 项 Python 回归、Go 官方商店 / CLI 及兼容修复检查通过。
- 本机成品的启动、内置组件校验、HTTPS 初始化、区域资源和界面检查通过；真实 EXE 搜索“美区 / iplayer”返回 5 条结果。GitHub 发布构建会另外验证生成的成品。
- 代理、Apple 服务状态、账号商店权限、应用许可及下架状态仍可能影响官方查询或下载。自动测试不等于使用真实账号完成历史 IPA 下载；本轮未代用户执行真实账号购买或下载验证。
- 每次主动密码登录、注销或退出清理本地凭据；验证码流程保留当前挑战。Apple 是否要求双重认证及推送手机通知由其服务端决定，清理本地会话不能保证每次推送，也不等于撤销服务端设备信任。
- 成品已内置组件和私有认证证书，普通用户不需要 Python、Go 或手动安装证书。首次缺少 Apple 运行组件时，由认证组件下载并校验，仍需要可用网络。

## English

Updates the backend to a reproducible upstream ipatool 2.8.1 compatibility build.
Fixes Apple-root download HTTP 403 with a pinned client-private certificate,
missing packaged HTTPS-policy data, and known-storefront discovery failures.
Adds immediate account-region synchronization, localized setup messages,
unclipped startup links and vector dropdown chevrons. No Windows certificate
store changes, disabled TLS verification or administrator setup are required.

Build overlays use normalized line endings to preserve the pinned engine hash
across Windows checkouts. The 75 Python regression checks and Go store/CLI tests pass. Packaged startup,
HTTPS and region-resource checks pass; the actual EXE returns five results for
the US `iplayer` search. Automated checks do not establish successful
real-account historical IPA downloads. Apple still controls 2FA challenges,
device notifications, storefront rights and app-license availability.
